## projects

### Climatize

A base project created for people who want to study and
experiment with web development.

Climatize combines an AI integration with a climate data API
inside a detailed weather dashboard, making it a practical
example for studying APIs, data processing and AI integration.

`PHP` `JavaScript` `APIs` `AI` `Open-Meteo`

### Comercial sites

experience, and can be adapted to different businesses.

`Next.js` `React` `TypeScript` `CSS`

### currency analytics platform

A project base for studying financial data and API integration.

The platform uses APIs to convert currencies and display stock
market information, combined with an interactive world map
showing the currencies used by different countries.

The project was created as a study base for working with APIs,
financial data, currency conversion and interactive data
visualization.

`JavaScript` `APIs` `Financial Data` `Currency Conversion` `Maps`
